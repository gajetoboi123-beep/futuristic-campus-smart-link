# Campus Connect - Futuristic Campus Smart Link

Live Website: https://futuristic-campus-smart-link.base44.app

Lesson 2 - Home page with Announcements, Events, Lost and Found, Directory.

## What is this?
Campus Connect is a campus website made in Base44. Students can view announcements, events, and lost items on the Home page.

## Batch Files
- 01-install-libraries.bat - Install libraries and create install log
- 02-run-app.bat - Run the app and create run log
- 03-connect-github.bat - Connect this folder to GitHub
